# Practice Test (Local)

How to use:

- Open `index.html` in a browser (serve via static server for best results).
- Click `Select questions file` and choose a `.txt` file containing questions.
- File format: questions numbered, options A–E on separate lines. Mark the correct option with an asterisk `*` or the word `(correct)`.

Example snippet:

1. Question text
A. Option one
B. Option two *
C. Option three
D. Option four
E. Option five

Behavior:
- 20 questions per page. Next moves to the next page. After the second page (40 questions) Submit will show your score.
- Selections are retained while navigating pages.
- Score >= 70% is Pass (green); otherwise Fail (red).

If you'd like, add your real questions file named `questions.txt` and upload it in the page.
